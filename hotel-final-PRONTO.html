🔧 Configurar Firebase

Cole aqui as credenciais do seu projeto Firebase para que todos os funcionários compartilhem os mesmos dados em tempo real.

Como obter as credenciais:
1. Acesse console.firebase.google.com
2. Crie um projeto → clique em "Web" (</>)
3. Copie o objeto firebaseConfig que aparecer
4. Cole cada campo abaixo e clique em Conectar
❌ Preencha todos os campos corretamente.
